Lesson 05（tmux 基础）

01 任务背景 · Mission Context

上节课你学会了 tmux 的基本姿势：建会话、分屏、detach。但你发现自己的用法还是「笨拙」的——

  • 🪟 想开第二个「标签页」却只会再开一个 ssh 终端，桌面乱成一团。
  • 🖱️ 想回滚看上面的日志，鼠标滚轮却毫无反应。
  • ⌨️ 每次都要按别扭的 Ctrl-b % 分屏，手指打架。

真正的 tmux 高手，不是「知道命令多」，而是把高频操作调教到顺手、把多任务组织成一套看得懂的布局。这一课，你要做三件事：驾驭窗口（多标签）、驾驭窗格（缩放/布局/回滚复制）、定制配置（改键位、开鼠标）——全部不需要 root，你自己家目录就能搞定。

Context → Need → Tool

多任务要组织、日志要回滚、键位要顺手 → 需要窗口管理 + 窗格进阶 + 配置文件 → 用 window、copy-mode、~/.tmux.conf。

02 知识 · Knowledge（≤25%，约 15–20 分钟）

3 个概念。每个：中文 + 英文 + 心智模型 + SVG + 语法 + 实例 + 边界情况 + 工程场景 + 衔接点。

概念 1 · 窗口（Window）：一个会话里的多个「标签页」

中文：一个 tmux 会话里可以有多个窗口，每个窗口是一个独立的「全屏标签页」，有自己的编号和名字。窗口之间来回切，比开一堆终端窗口清爽得多。

English: A session holds multiple windows — each a full-screen "tab" with its own number and name, switched between freely.

语法：

Ctrl-b c        # 新建窗口（当前会话内开个新标签）
Ctrl-b ,        # 重命名当前窗口（起个能看懂的名字）
Ctrl-b 0..9     # 直接跳到指定编号的窗口
Ctrl-b n / p    # 下一个 / 上一个窗口
Ctrl-b w        # 列出所有窗口，用方向键选
Ctrl-b f        # 按名字查找窗口
Ctrl-b &        # 关闭当前窗口（确认后）

实例：一个 RNA 项目，你会同时有「质控」「比对」「可视化」三件事。开三个窗口：0:qc、1:align、2:viz，Ctrl-b 1 一键切到比对，比在一个屏幕里堆三个分屏清爽。

边界情况 · 常见失败
  • 窗口多了记不住编号：编号是 0 开始，超过 9 个窗口 Ctrl-b 数字 就跳不到 10+ 了，这时用 Ctrl-b w 列表选，或 Ctrl-b n/p 循环。
  • 忘了给窗口起名：默认名字是「当前命令」，过一会全变成 bash 分不清谁是谁。开窗口第一件事就 Ctrl-b , 改名。
  • Ctrl-b & 误关窗口：会弹确认（kill-window xxx? (y/n)），按 y 才真关，手滑按别的键就取消。
工程场景 · 为什么需要它

「一个窗口 = 一件任务」，是远程工作最清晰的整理方式：QC 在 0、比对在 1、画图在 2。三个月后回来 tmux attach，扫一眼状态栏的窗口名就知道「这个项目进行到哪了」。

衔接点

窗口是 session 和 pane 之间的「中间层」：一个 session 装多个 window，一个 window 里再分多个 pane。概念 2 讲 pane 的进阶玩法。

概念 2 · 窗格进阶：缩放 / 布局 / 调整 / 回滚复制（copy-mode）

中文：窗格（pane）是窗口里的分屏。进阶玩法四件套：缩放（把某窗格临时放大全屏）、布局（切换分屏排列）、调整大小、回滚与复制（进入 copy-mode 翻看历史、复制文字）。

English: Advanced pane skills: zoom (temporarily full-screen a pane), layout (rearrange splits), resize, and copy-mode (scroll back and copy text).

语法：

Ctrl-b z          # 缩放：当前窗格全屏 / 还原（最常用！）
Ctrl-b space      # 循环切换分屏布局
Ctrl-b o          # 按顺序循环切换窗格
Ctrl-b {  /  }    # 把当前窗格左移 / 右移（交换位置）
Ctrl-b x          # 关闭当前窗格

# 调整窗格大小（按住 prefix 后，再按 Ctrl+方向键，可重复）
Ctrl-b 然后 Ctrl+←/→/↑/↓   # 微调边界

# 回滚与复制（copy-mode）
Ctrl-b [          # 进入回滚/复制模式
PgUp / PgDn      # 翻页看历史输出
q                # 退出 copy-mode
Ctrl-b ]          # 粘贴刚才选中的文字

实例：你在一个窗格里 tail -f 看日志，想仔细看上面滚过去的一段：Ctrl-b z 把日志窗格放大全屏，Ctrl-b [ 进入回滚模式慢慢翻，看完 q 退出、再 Ctrl-b z 还原。

边界情况 · 常见失败
  • 鼠标滚轮没反应：tmux 默认不接管鼠标，滚轮滚的是终端自己的历史。开鼠标要在配置里 set -g mouse on（概念 3），否则只能用 Ctrl-b [ 回滚。
  • Ctrl-b ] 贴出来不是你要的：tmux 的 buffer 和系统剪贴板是两套，跨应用复制要配置或用 Ctrl+Shift+C/V。
  • copy-mode 里乱按：copy-mode 里 q 是退出，Esc 也行；别用 Ctrl-c（那是打断命令）。
工程场景 · 为什么需要它

看日志是生信的日常：任务报错了，你要回滚翻那几行 error。Ctrl-b z + copy-mode 让你在「全屏看日志」和「分屏干活」之间一秒切换，这是资深工程师最顺手的动作。

衔接点

copy-mode 的「翻页看历史」思路，和 Lesson 07（grep）的「从日志里捞关键词」是黄金搭档。概念 3 把前面所有操作用配置文件固化下来。

概念 3 · 配置文件 ~/.tmux.conf：改键位 / 开鼠标 / 多会话

中文：tmux 的所有习惯都能写进你家目录的 ~/.tmux.conf 里持久化——改前缀键、开鼠标滚动、设置回滚行数、自定义分屏快捷键。这是普通用户就能改的文件（不需要 root）。

English: tmux habits live in ~/.tmux.conf — remap the prefix, enable mouse, set scrollback, bind custom keys. It's your own file; no root needed.

语法（一份实用配置）：

# ~/.tmux.conf —— 我的 tmux 配置
set -g mouse on                 # 开鼠标：滚轮回滚、点窗格切换
set -g history-limit 10000      # 回滚历史行数加大
set -g default-terminal "screen-256color"   # 256 色，vim 配色更正常

# 把前缀从 Ctrl-b 改成更顺手的 Ctrl-a（可选）
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# 用 | 和 - 分屏，比 % 和 " 更好记（可选）
bind | split-window -h
bind - split-window -v

# 改完保存后，在 tmux 里生效：
tmux source ~/.tmux.conf

多会话管理（配套）：

tmux ls                          # 列出所有会话
tmux rename-session -t old new   # 重命名会话（或 Ctrl-b $）
tmux kill-session -t name        # 关闭指定会话
tmux kill-server                 # 关闭所有会话（慎用）
边界情况 · 常见失败
  • 改配置不生效：改了 ~/.tmux.conf 但当前会话还是旧的，要 tmux source ~/.tmux.conf 重新加载；新开的会话才自动读配置。
  • 改了 prefix 后记不住：把 Ctrl-b 改成 Ctrl-a 后，本课所有 Ctrl-b 都要换成 Ctrl-a。刚开始建议先用默认的，熟练了再改。
  • 拼错配置项：tmux 配置错了通常不报错、只是那条静默失效，所以要逐条确认。
工程场景 · 为什么需要它

把习惯写进配置 = 把「上手成本」一次性付清。换新服务器时，scp ~/.tmux.conf 新机器:~/.tmux.conf 一键带走你的整套习惯，在哪都是熟悉的环境——这是工程师的「可迁移资产」。

衔接点

配置文件的思路，和 Lesson 14（Bash 脚本的 ~/.bashrc）同源：都是「把偏好固化到点文件（dotfile）」。这套本事贯穿你整个 Linux 生涯。

05 排错挑战 · Debug Challenge

5 个真实 Ubuntu Server 24.04 会遇到的报错。每题 Problem → Think → Answer → Explanation。

调试 1 · 鼠标滚轮在 tmux 里没反应
Problem：进 tmux 后鼠标滚轮不能回滚历史。
💭 Think：tmux 默认接管鼠标吗？
Answer：配置里加 set -g mouse on，然后 tmux source ~/.tmux.conf。
🧠 Explanation：tmux 默认 mouse off，滚轮事件不交给 tmux 处理，所以回滚不了。开 mouse 后滚轮进入 copy-mode、点窗格还能切换。
调试 2 · 改了 ~/.tmux.conf 但没生效
Problem：改完配置，新键位/鼠标还是旧的。
💭 Think：改对文件了吗？重新加载了吗？
Answer：确认改的是 ~/.tmux.conf，然后 tmux source ~/.tmux.conf 重新加载当前会话；全新会话会自动读。
🧠 Explanation：配置只在 tmux 启动时读一次，运行中的会话不会自动重读，必须 source 手动加载。
调试 3 · Ctrl-b % 分屏没反应
Problem：按 Ctrl-b % 没分屏。
💭 Think：前缀键被改了吗？还是你不在 tmux 里？
Answer：先确认在 tmux 里（状态栏在底部）；如果改过 prefix，要用新前缀。用 tmux show-options -g prefix 查看当前前缀。
🧠 Explanation：改了 prefix（如 C-a）后，所有 Ctrl-b 都要换成新前缀，忘掉这点就会「怎么按都没反应」。
调试 4 · Ctrl-b ] 贴出来的不是系统剪贴板内容
Problem：在 tmux 里 Ctrl-b ] 粘贴，出来的是旧内容。
💭 Think：tmux 的 buffer 和系统剪贴板是一回事吗？
Answer：tmux 有自己独立的 buffer，和系统剪贴板分离。跨应用粘贴用终端的 Ctrl+Shift+C/V；tmux 内部复制粘贴用 copy-mode 选中 + Ctrl-b ]。
🧠 Explanation：两套剪贴板不互通。开 mouse 后可以直接鼠标拖动选中、Ctrl+Shift+C 复制走系统剪贴板。
调试 5 · 窗口/窗格越开越多，找不到路了
Problem：分屏分多了，忘了自己在哪个窗格、有几个窗口。
💭 Think：有什么命令能「看全景」？
Answer：Ctrl-b w 列出所有窗口；Ctrl-b q 显示每个窗格编号（按编号跳）；Ctrl-b z 放大当前窗格理清思路；Ctrl-b x 关掉多余的。
🧠 Explanation：tmux 提供了「地图」类命令帮你导航：w 看窗口列表、q 看窗格编号。迷路时先看地图，别硬切。

06 工程场景 · Engineering Scenarios

先写下你自己的方案，再展开看参考答案。每个场景都要想「三个月后的人能否一眼看懂」。

场景 1：一个 RNA 项目你要同时做「质控、比对、可视化」三件事，还偶尔要看总日志。怎么用 tmux 组织，让三个月后的自己（或同事）一看就懂？

参考方案

会话名 = 项目，窗口名 = 阶段：

tmux new -s PRAD          # 会话 = 项目
Ctrl-b , 改名 qc          # 窗口 0 = 质控
Ctrl-b c → 改名 align     # 窗口 1 = 比对
Ctrl-b c → 改名 viz       # 窗口 2 = 可视化

状态栏一眼看到 0:qc 1:align 2:viz，谁接手都懂。

场景 2：你在一个窗格里看日志，想同时对比另一个窗格里的脚本，但两个窗格都太小看不清。怎么办？

参考方案

用 Ctrl-b z 临时放大：看日志时放大日志窗格，看完还原；改脚本时放大 vim 窗格。zoom 是「临时全屏」，不破坏分屏布局，是比频繁重新分屏更优雅的做法。

场景 3：换了新服务器，你想一键带回自己那套 tmux 习惯（键位、鼠标、配色）。怎么把「习惯」变成可迁移资产？

参考方案

把习惯写进 ~/.tmux.conf，换机器时 scp ~/.tmux.conf 新机器:~/.tmux.conf 拷过去即可。配置文件就是你的「可迁移工作环境」——和 ~/.bashrc、vim 配置一起，组成你的 dotfiles 资产库。

场景 4：你同时维护三个项目（PRAD 比对、雅思脚本、LeetCode 题解），怎么用多会话把它们隔开、互不干扰？

参考方案

每个项目一个命名会话：tmux new -s PRAD、tmux new -s ielts、tmux new -s lc。用 tmux ls 看全局，tmux attach -t PRAD 切进对应项目。会话隔离 + 命名清晰 = 多项目并行不打架。

07 Boss 战 · Boss Fight（15–20 分钟）

任务：用 tmux 搭一套「边改脚本、边看日志、边查结果」的完整工作流，并修好一个被埋的坑。

要求（可度量交付物）：

  • 建会话 PRAD，窗口 0 改名 dev、窗口 1 改名 logs。
  • 窗口 0 里左右分屏：左窗 vim run_pipeline.sh、右窗 tail -f results.log。
  • 用 Ctrl-b z 放大日志窗格，Ctrl-b [ 回滚找到一行报错，截图。
  • 写一份自己的 ~/.tmux.conf（开鼠标 + 加大历史 + 自定义分屏键），source 生效。
  • Ctrl-b d 脱离，再 tmux attach 接回，截图证明工作流没丢。
⚠️ 埋了一个坑

你的 ~/.tmux.conf 里改前缀键时，只写了 set -g prefix C-a 却忘了 unbind C-b，导致新旧前缀混乱、分屏键按了没反应。你要自己发现「为什么 Ctrl-b % 突然失灵」，补上 unbind C-b + bind C-a send-prefix 修好，并截图「发现 → 修复」。

验收清单：会话/窗口命名 ✅ 分屏+日志 ✅ zoom+回滚 ✅ 配置文件生效 ✅ 脱离接回 ✅ 埋坑已修复 ✅ 截图 + 命令进 github/lesson05b/ 并 git push ✅。

Concepts

FrontBack
tmux 三层结构？session 会话 → window 窗口 → pane 窗格
window 和 pane 区别？window 是「标签页」（独立全屏），pane 是窗口里的分屏
copy-mode 是什么？回滚看历史 + 复制文字的模式（Ctrl-b [ 进入）
tmux 配置文件在哪？~/.tmux.conf（自己家目录，无需 root）
改了配置为什么不生效？要 tmux source 重新加载，或开新会话
为什么改 prefix 要 unbind C-b？不 unbind 旧前缀会和新前缀并存，导致混乱
