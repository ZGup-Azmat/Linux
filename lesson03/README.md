## 本课学了什么（核心知识点）

### 1. 权限三元组：属主 / 属组 / 其他人 × 读写执行
- `ls -l` 第一列 10 个字符：`-` 类型位 + 3 × (rwx)
- 三类人：owner 属主 / group 属组 / others 其他人
- 三种能力：r 读 / w 写 / x 执行
- ⚠️ **目录的 r/w/x 含义和文件完全不同**：目录的 x = 能 cd 进入，r = 能 ls 列出，w = 能增删文件

### 2. chmod：改权限（符号 + 八进制）
- 符号模式：`u/g/o/a` + `+/-/=` + `r/w/x`
- 八进制：r=4 w=2 x=1，`755` = rwxr-xr-x
- 常用：`644` 文件 / `755` 脚本目录 / `600` 私有文件 / `700` 私有目录 / `1777` sticky
- ⚠️ `=` 是覆盖，`+` 是叠加；`-R` 递归会改整棵树

### 3. chown / chgrp：改属主与属组
- `chown user:group file` 同时改属主属组
- `chgrp group file` 只改属组
- ⚠️ 普通用户不能随便 chown 别人（需 sudo），否则 `Operation not permitted`

## 记忆锚点

- r=4 w=2 x=1，rwx=7
- 目录的 x = 进入的门票（没有 x，cd 都进不去）
- 只读数据用 `444`，脚本用 `+x`，共享防删用 `1777`（sticky）
- chown 改属主（需 sudo），chgrp 改属组，`user:group` 一起改
