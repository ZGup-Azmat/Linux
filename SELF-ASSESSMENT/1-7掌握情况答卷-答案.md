# A 卷 · 答案

### 第 1 题
```bash
mkdir -p PRAD_2026/{raw,trimmed,results,logs}
ls -R PRAD_2026        # 或 tree PRAD_2026
```
花括号 `{a,b,c,d}` 一次展开四个目录，`-p` 保证父目录自动创建。

### 第 2 题
```bash
cd PRAD_2026/raw
touch patient{01..06}.bam
ls
```
`{01..06}` 是 bash 的范围展开，生成 01~06（带前导零）。

### 第 3 题
```bash
touch tumor.vcf normal.vcf run_pipeline.sh
```

### 第 4 题
```bash
cd results                      # 相对路径（从 PRAD_2026 下）
pwd
cd ../..                        # 先退出来
cd ~/PRAD_2026/results          # 绝对路径（~ 展开成家目录）
# 或 cd /home/user/PRAD_2026/results
pwd
```
相对路径从「当前目录」出发；绝对路径从根 `/` 出发，`~` 展开成家目录的绝对路径。

### 第 5 题
```bash
cd PRAD_2026/logs
printf 'INFO: start\nERROR: bam truncated\nWARNING: low memory\n' > align.log
cat align.log
```

### 第 6 题
```bash
find PRAD_2026/raw -name "*.bam"
find PRAD_2026/raw -type f -name "*.bam"   # 只找文件，排除同名目录
```
`-name` 模式必须加引号，防止 shell 先展开 `*`。

### 第 7 题
```bash
find PRAD_2026 -name "*.sh" -exec chmod +x {} \;
# 或批量传参：find PRAD_2026 -name "*.sh" -exec chmod +x {} +
ls -l PRAD_2026/raw/run_pipeline.sh   # 验证权限从 rw-r--r-- 变 rwxr-xr-x
```
`{}` 是每个匹配文件的占位符，`\;` 或 `+` 是 -exec 的结束标记（漏了会报 missing argument）。

### 第 8 题
```bash
find PRAD_2026 -name "*.vcf"
```

### 第 9 题
```bash
cd PRAD_2026/logs
grep -in "error" align.log
# 或从根目录：grep -in "error" PRAD_2026/logs/align.log
```
`-i` 忽略大小写（error 也能匹配 ERROR），`-n` 显示行号。

### 第 10 题
```bash
grep -c "error" align.log          # 数「含 error 的行数」→ 1（假设只有一行 ERROR）
grep -o "error" align.log | wc -l  # 数「error 出现的总次数」
```
两者可能不同：`-c` 数的是「行」，一行里 error 出现多次也只算 1；`-o` 只输出每个匹配的 error 词本身，`wc -l` 再数行 = 总次数。

### 第 11 题
```bash
cp PRAD_2026/raw/patient{01..06}.bam PRAD_2026/results/
# 等价：cp PRAD_2026/raw/patient0[1-6].bam PRAD_2026/results/
ls PRAD_2026/results
```
`patient0[1-6]` 比 `patient0?` 更精确（? 会匹配 0~9 共 10 个）。

### 第 12 题
```bash
basename results/patient03.bam   # → patient03.bam（取最后一段文件名）
dirname  results/patient03.bam   # → results（取前面的目录部分）
```
basename 取「文件名」，dirname 取「目录」，别搞反。

### 第 13 题
```bash
pushd PRAD_2026/results   # 压入当前目录，进入 results
dirs                      # 看目录栈
popd                      # 弹出，返回
```
`cd -` 只记「上一个」目录（只能来回一次）；`pushd/popd` 是一个栈，能存多个目录、任意穿梭。

### 第 14 题
```bash
chmod 755 run_pipeline.sh
ls -l run_pipeline.sh     # → -rwxr-xr-x 1 user user ...
```
10 字符 = 1 类型位 + 3 组 rwx：`-` 普通文件；`rwx` 属主可读可写可执行；`r-x` 属组可读可执行；`r-x` 其他人可读可执行。

### 第 15 题
```bash
chmod 700 raw
chmod 750 raw
```
**目录 vs 文件的 rwx 含义**（重点）：
- 文件：r=看内容、w=改内容、x=运行
- 目录：r=列出文件名（ls）、w=新建/删除/重命名文件、x=进入（cd）+ 访问里面文件

### 第 16 题
```bash
sudo chown colleague:bioinfo results
```
普通用户做不了：只有**属主或 root** 能 chown，普通用户改属主会报 `Operation not permitted`——这是安全设计，防止把文件「嫁祸」给别人。

### 第 17 题
```bash
id
groups
```
`id` 输出 `uid=1000(user) gid=1000(user) groups=1000(user),27(sudo),...`。**主组是第一个**（通常和用户名同名）。root 的 UID 是 **0**。

### 第 18 题
按键序列：`vim run_pipeline.sh` → `i` 进入插入 → 输入两行（含 tumor）→ `Esc` 回普通 → `:%s/tumor/normal/g` 回车 → `:wq` 保存退出 → `cat run_pipeline.sh` 验证。
`:%s/旧/新/g` 里的 `g` 表示整行所有匹配都替换，漏了 g 只换每行第一个。

### 第 19 题
```bash
tmux new -s pr
# 左右分屏：Ctrl-b %
# 左窗：vim run_pipeline.sh
# 切到右窗（Ctrl-b →）：tail -f align.log
```
左右分屏是 `Ctrl-b %`（上下是 `Ctrl-b "`），别记混。

### 第 20 题
```bash
# tmux 里：Ctrl-b d（脱离）
tmux ls                # 会话 pr 还在
tmux attach -t pr      # 接回
```
意义：任务跑在 tmux 会话里、不挂在你 ssh 连接上，断线/关电脑任务继续跑，回来 attach 接着看。

### 第 21 题
原因：`drw-r--r--` 缺了 **x（执行/进入）** 权限。cd 进目录需要 x，没有 x 连属主也进不去。
修：`chmod +x results/backup`（或 `chmod 755 results/backup`）。

### 第 22 题
原因：`-name *.bam` 没加引号，`*` 被 shell 先展开成当前目录的文件名，find 收到的不是「模式」。
改：`find . -name "*.bam"`。

### 第 23 题
原因：grep 默认区分大小写，`Error`（大写 E）匹配不到 `error`（小写）。
两条解法：① `grep -i "error" align.log`；② `grep "error" align.log`（用小写）。

### 第 24 题
原因：`-c` 统计「匹配的**行数**」，一行里 error 出现多次只算 1；`-o | wc -l` 统计 error 出现的「**总次数**」（-o 只输出每个匹配词，wc -l 数行）。所以 -c ≤ -o|wc -l。

### 第 25 题
find 是「按标签找文件」（名字/大小/日期），grep 是「翻文件找字」（内容里搜关键词）。find 管「哪个文件」，grep 管「文件里的哪行/哪个词」。

### 第 26 题
目录的 x = 「进入的门票」：没有 x，你连 `cd` 都进不去，更别说访问里面的文件。即使有 r（能列出）、w（能改），没 x 也等于门焊死。

# B 卷 · 答案

### 第 1 题
```bash
mkdir -p RNA_seq/{fastq,aligned,counts,reports}
ls -R RNA_seq
```

### 第 2 题
```bash
cd RNA_seq/fastq
touch SRR{1001..1008}_1.fastq.gz
ls
```

### 第 3 题
```bash
cd RNA_seq
touch genes.tsv multiqc_report.html align.sh qc.log
```

### 第 4 题
```bash
cd RNA_seq/fastq
cd ../aligned
cd -        # 回到 fastq（上一个目录）
```
`cd -` 只记「上一个」目录（存在 OLDPWD 变量里），来回切两次就到不了更早的目录。

### 第 5 题
```bash
cd RNA_seq
printf 'PASS sample1\nPASS sample2\nFAIL sample3\nWARN sample4\n' > qc.log
cat qc.log
```

### 第 6 题
```bash
ls fastq/*_1.fastq.gz
```
`*` 匹配任意多个字符，`?` 匹配**恰好一个**字符。
`SRR100?.fastq.gz`：`?` 只匹配 SRR100 后的一个字符，所以它匹配「SRR100 + 单个字符 + .fastq.gz」这种名字；本目录文件是 `SRR1001_1.fastq.gz`（SRR1001 后面还有 `_1`），所以**匹配不到**——这正是 ? 和 * 的区别所在。

### 第 7 题
```bash
find fastq -name "*.gz"
find fastq -name "*.gz" -size +1M
```
注意：`touch` 建出来的 .gz 是 **0 字节空文件**，所以 `-size +1M` 一条都匹配不到——这是 `-size +`（严格大于）的正确行为，不是你写错了。想验证可以 `ls -lh fastq/*.gz` 看它们都是 0。

### 第 8 题
```bash
find RNA_seq -type f | wc -l
```
管道：`find` 每输出一个文件占一行，`wc -l` 数行数 = 文件总数。这就是「管道 |」把两个工具接起来。

### 第 9 题
先给 genes.tsv 造点数据（含 BRCA1）：
```bash
printf 'TP53\t3.2\nBRCA1\t5.1\nEGFR\t2.8\n' > genes.tsv
grep -n "BRCA1" genes.tsv
```
`-n` 带行号。

### 第 10 题
```bash
grep "FAIL" qc.log                # ① 含 FAIL 的行
grep "FAIL" qc.log | grep -v "WARN"   # ② 含 FAIL 但排除含 WARN（管道 + 反选）
```
第②条演示「grep 结果再喂给 grep」的管道组合。本数据里 FAIL 行不含 WARN，所以结果不变，但写法是通用的。

### 第 11 题
```bash
which bash        # → /usr/bin/bash（命令在哪）
realpath .        # → 当前目录的绝对路径
```
which 找命令真身，realpath 把相对路径解析成绝对路径。

### 第 12 题
```bash
find RNA_seq -name "*.sh" -mtime -30
```
`-mtime -30` 是「近 30 天」；`+30` 才是「30 天前」。负号 = 最近，别搞反。

### 第 13 题
```bash
touch {tumor,normal}.fastq.gz
basename tumor.fastq.gz     # → tumor.fastq.gz
```
`{a,b}` 花括号展开成两个名字，basename 取最后一段文件名。

### 第 14 题
```bash
chmod u+x align.sh
ls -l align.sh    # → -rwxr-xr-x（第 4 位从 - 变 x）
```
符号模式（u/g/o + r/w/x）适合「改某一个权限」；八进制（644/755）适合「一次设完整权限」。

### 第 15 题
```bash
chmod 755 reports
```
目录要 755 而不是 644：目录需要 **x** 才能被进入、需要 **r** 才能被列出。644 目录（rw-r--r--）缺 x，别人进不去、你也不能 cd 进去。

### 第 16 题
```bash
sudo chown root:lab aligned
```
普通用户执行会报 `Operation not permitted`：只有属主或 root 能改属主，这是安全设计。

### 第 17 题
```bash
getent passwd user
# → user:x:1000:1000:,,,:/home/user:/bin/bash
```
7 字段：用户名 / 密码占位 / UID / GID / 描述 / 家目录 / shell。第 3 个是 UID（1000），第 6 个是家目录（/home/user）。

### 第 18 题
按键序列：`vim genes.tsv` → `i` 写 3 行 → `Esc` → 光标到第 3 行 → `dd`（删行）→ 光标到第 1 行 → `yy`（复制）→ `G`（到文件尾）→ `p`（粘贴）→ `:wq` → `cat genes.tsv` 验证。
`dd` 其实是「剪切」，`p` 能贴回来；`yy` 复制 + `p` 粘贴；`u` 撤销。

### 第 19 题
```bash
tmux new -s rna
# 上下分屏：Ctrl-b "（注意是双引号键，不是 %）
# 上窗格：看文件；下窗格：跑命令（Ctrl-b ↑/↓ 切换）
```
上下分屏 `Ctrl-b "`，左右分屏 `Ctrl-b %`，别记混。

### 第 20 题
copy-mode（`Ctrl-b [`）是「回滚看历史 + 复制文字」的模式：进入后能用方向键/PgUp/PgDn 翻看之前滚过去的输出，`q` 退出。
它和鼠标滚轮的关系：默认 tmux 不接管鼠标，滚轮没反应；配置里加 `set -g mouse on` 后，鼠标滚轮就能直接回滚（内部也是走 copy-mode）。

### 第 21 题
原因：`drwxr-xr--` 的「其他人」组是 `r--`，缺了 **x**，所以非属主/非组员进不去、列不出。
修：`chmod 755 fastq`（或 `chmod o+x fastq`）。

### 第 22 题
原因：`-exec` 必须以 `\;` 或 `+` 结尾，你漏了。
改：`find . -exec chmod +x {} \;`。

### 第 23 题
至少两个可能原因：
① `*.gz` 是压缩二进制文件，grep 默认可能跳过或乱码（加 `-a` 当文本、或 `-I` 跳过二进制）；
② 文件是 gzip 压缩的，里面是二进制数据，`SRR1001_1.fastq` 这个字符串根本不以明文存在（要先 `zcat` 解压再 grep）。

### 第 24 题
原因：目录 600 = `rw-------`，缺了 **x**，连属主自己都 `cd` 不进去。
修：`chmod +x 目录`（或 `chmod 700 目录`）。

### 第 25 题
符号模式（`chmod u+x`）是「增量改」——加/减某一个权限；八进制（`chmod 755`）是「整体覆盖」——一次把三组权限全部设死。微调用符号、设标准权限用八进制。

### 第 26 题
目录的 `w` 权限 = 能在目录里新建/删除/重命名文件；**sticky bit**（如 1777）= 在这个目录里，**只有文件属主能删自己的文件**。共享目录要「谁都能写、但谁都不能删别人的」就配 sticky bit（/tmp 就是这么干的）。
