## 本课学了什么（核心知识点）

### 1. Basic matching 基础匹配
- `grep "error" align.log` 打印含 error 的行
- `-i` 忽略大小写、`-n` 显示行号、`-v` 反选（不含）
- ⚠️ 默认区分大小写；短语含空格要加引号

### 2. Recursive & counting 递归与统计
- `-r` 递归搜目录、`-c` 统计行数、`-l` 只列文件名
- ⚠️ `-c` 数的是「行」不是「次数」（次数用 `-o | wc -l`）

### 3. Regular expressions 正则
- `^` 行首、`$` 行尾、`[0-9]` 字符类、`.` 任意字符、`|` 或（需 -E）
- ⚠️ `.` 是任意字符，真正的点号要 `\.`

## 记忆锚点

- find 找文件，grep 找内容（黄金搭档）
- grep 默认区分大小写，加 -i 忽略
- `-c` 数行，`-o | wc -l` 数次数
- 正则 `.` = 任意字符，`^` = 行首，`$` = 行尾
