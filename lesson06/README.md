## 本课学了什么（核心知识点）

### 1. find 基本结构：路径 + 条件 + 动作
- `find 从哪找 什么条件 做什么`（默认动作 -print 打印路径）
- `-name "*.bam"` 的引号不能省（防 shell 提前展开 *）
- ⚠️ -name 区分大小写，不分大小写用 -iname

### 2. 条件过滤
- `-type f/d/l` 类型、`-size +2G` 大小、`-mtime +30/-7` 时间
- `-and`（默认）/`-o`（或）组合多条件
- ⚠️ -size 100k 是「约 100KB」，不是精确值；-mtime +30 是 31 天起

### 3. 对结果执行动作
- `-exec 命令 {} \;`（{} 代表每个文件）
- `-delete` 删除、`2>/dev/null` 屏蔽权限报错
- ⚠️ 铁律：先 -ls 验证，再 exec/delete；rm 极危险

## 记忆锚点

- find = 路径 + 条件 + 动作，默认打印
- `-name` 要引号；`-size`/`-mtime` 的 `+` = 大于/更早
- 先 `-ls` 看，再 `-exec`/`-delete` 动
- `2>/dev/null` 屏蔽 Permission denied
