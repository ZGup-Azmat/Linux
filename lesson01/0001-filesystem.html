02 知识 · Knowledge（≤20%）

本课只有 3 个概念。每个概念：中文 + 英文 + 心智模型 + 图 + 语法 + 实例 + 常见错误。

概念 1 · Linux 文件系统是一棵树

中文：Linux 没有 Windows 的 C 盘、D 盘。一切从根目录 / 开始，所有硬盘、文件夹、U 盘都「挂载」到这一棵树的某个分支上。

English: Linux has no drive letters. Everything starts from the root /, and every disk or folder is mounted somewhere on this single tree.

语法：ls / 查看根目录下有什么。

实例：/home/user 是你登录后默认待的地方，缩写为 ~。

常见错误

把根目录 / 和 root 用户的家目录 /root 搞混。它们不是一回事：/ 是整棵树的顶点，/root 只是超级用户 root 的家目录。

概念 2 · 绝对路径 vs 相对路径

中文：定位一个文件有两种说法：从根目录 / 出发说全称叫绝对路径；从你「现在站的位置」出发叫相对路径。

English: An absolute path starts from /; a relative path starts from where you currently are.

心智模型：导航时——. = 我在这，.. = 上一层，~ = 家目录。

语法：

pwd        # 我在哪？print working directory
cd /home   # 绝对路径：从根出发
cd ..      # 相对路径：回上一层
cd ~       # 回家目录

实例：你现在在 /home/user/data：

  • 绝对路径指向样本：/home/user/data/raw/patient001.fastq.gz
  • 相对路径指向样本：raw/patient001.fastq.gz
常见错误

以为 ~ 是根目录。实际上 ~ 是你自己的家目录（如 /home/user），而根目录是 /。

概念 3 · 查看与创建：ls / mkdir / touch

中文：管理文件的第一步是看（ls）和建（mkdir 建目录、touch 建空文件）。

English: First see with ls, then create with mkdir (directories) and touch (empty files).

语法：

ls -l       # 长格式：权限 属主 属组 大小 时间 名字
ls -a       # 含隐藏文件（以 . 开头）
mkdir -p a/b/c   # 递归创建多级目录
touch patient001.fastq.gz   # 创建空文件

实例：读一段 ls -l 输出：

-rw-r--r-- 1 user user 0 Sep  8 10:00 patient001.fastq.gz
drwxr-xr-x 2 user user 4096 Sep  8 10:00 raw_data
# 第一个字符 - 是普通文件，d 是目录
常见错误

mkdir 创建已存在的目录会报错 File exists；touch 不会报错，但只创建空文件（大小 0），不是用来写内容的。

05 排错挑战 · Debug Challenge

5 个真实会遇到的报错。先自己想，再点开看答案。

调试 1 · mkdir /root/x → Permission denied

原因：你试图在 /root（超级用户的家目录）里建目录，但你的普通用户没有写权限。

解决：别在 /root 下操作；用你自己的 ~/ 或 /tmp。

调试 2 · lss → command not found

原因：拼写错误，没有 lss 这个命令，正确的是 ls。

解决：检查拼写；用 Tab 键自动补全。

调试 3 · cd /data → No such file or directory

原因：/data 这个绝对路径不存在。你可能想进的是 ~/data（家目录下的 data）。

解决：分清绝对路径和相对路径；先 ls 确认目标存在。

调试 4 · 写文件报 No space left on device

原因：磁盘满了（或超出配额 quota）。

解决：用 df -h 查看磁盘使用；清理 /tmp 或大文件。

调试 5 · mkdir a/b/c → No such file or directory

原因：父目录 a/b 不存在，普通 mkdir 不会自动创建父目录。

解决：用 mkdir -p a/b/c。

06 工程场景 · Engineering Scenarios

场景 1：测序中心有 500 个样本文件，名字是 SRR12345678_1.fastq.gz 这种。你怎么组织目录，让三个月后还能一眼找到某个样本？（提示：按项目 / 日期 / 样本分三层。）

参考思路

三层结构：project/date/sample/，例如 TCGA_PRAD/2026-09-08/SRR12345678/。目录名即元数据，文件名里保留原始 ID。

场景 2：你会用 rm 删除文件。它不可恢复。设计三条你自己的「防误删」规则。

参考思路

① 删前先 ls 确认；② 重要数据先 cp 备份；③ 用 rm -i（删除前询问）或先 mv 到 /tmp 观察几天再删。

场景 3：为 6 位研究员设计一套目录：每个人只能在自己的目录里操作，且能共享一个公共数据目录。先用目录结构描述你的方案（权限细节到 Lesson 03 才学）。

参考思路

/data/shared/（公共）+ /data/users/{zhang,wang,li,...}/（每人一个）。公共目录只读，个人目录可写。
