# Lesson 01 · Notes · The Linux Filesystem

## 三个核心概念

1. **一棵树**：Linux 没有盘符，一切从 `/` 开始。`/home` 家目录、`/etc` 配置、`/var` 日志、`/tmp` 临时、`/usr` 软件。
2. **两种路径**：绝对路径从 `/` 出发；相对路径从当前位置出发。`. `= 这，`..` = 上一层，`~` = 家目录。
3. **四件套**：`pwd`（我在哪）、`ls`（看）、`cd`（走）、`mkdir`/`touch`（建）。

## 我自己的话复述（费曼）

> 垃圾场就是一个 / ，而每一个具体的分类就是一个home，比如说家具垃圾、塑料垃圾、家电垃圾 ... /etc就是这个垃圾场能干什么，分解垃圾、压缩垃圾、烧垃圾、运垃圾 ，而那个 /var 就是记垃圾场每天都执行了啥操作，比如说运垃圾，那就会记上运了垃圾，烧垃圾就记烧垃圾等等，/tmp 就是放一会的垃圾（或许会有价值，因为一些东西总是在失去时，才能体会到他的珍贵，比如好吧没想出来），/usr 就是讲这些 /var中的运动中，能使用的工具的型号，你懂得不想敲字了

## 记忆锚点

- `mkdir -p` = 自动把缺的父目录也建好（不用一层层建）
- `rm` 删了回不来，删前先 `ls`
- `ls -l` 第一个字符：`-` 文件、`d` 目录
