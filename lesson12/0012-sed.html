01 Mission Context 任务背景

awk 能按列「算」，但改不了行里的文字。今天主管丢给你一堆要批量改的文本：

  • 📝 一个样本清单，把所有 chr1 前缀去掉，只留数字（chr1 → 1）。
  • 🧹 一个 VCF/GTF 文件，删掉所有 # 开头的注释行。
  • 🏷️ 一个基因表，把样本名 Sample_01 统一改成 SRR00001（批量改名）。
  • 📄 一个报告，只要第 5 行到第 20 行，其余不要。

sed（stream editor 流编辑器）就是干这个的——逐行读入，按「替换 / 删除 / 打印」规则处理每一行，输出改后的文本。它是批量文本清洗的第一利器。

Context → Need → Tool

要批量替换/删除/提取「行内文字」 → 需要一个流编辑器 → sed（s/old/new/ 替换、地址定位、d/p 删除打印、-i 原地修改）。

02 Knowledge 知识（≤25%，约 15–20 分钟）

3 concepts. Each: 英文定义 + 中文注释 + 心智模型 + 语法 + 实例 + 边界情况 + 工程场景 + 衔接点。

Concept 1 · Substitute: s/old/new/ and its flags

English: sed 's/old/new/' replaces the first match on each line; add g to replace all (s/old/new/g), or a number to replace the nth (s/old/new/2).

中文：sed 's/old/new/' 替换每行第一个匹配；加 g 替换所有（s/old/new/g），加数字替换第 n 个（s/old/new/2）。

Syntax：

sed 's/old/new/' file        # 每行第一个 old → new
sed 's/old/new/g' file       # 每行所有 old → new（g=global）
sed 's/old/new/2' file       # 每行第二个 old → new
sed 's|/old/|/new/|' file    # 换定界符 |，避免转义斜杠
sed 's/chr//g' sample.txt    # 删掉所有 chr（new 为空）

实例：sed 's/chr//g' sample.txt 把「chr1、chr22、chrX」统一变成「1、22、X」，方便后面做数值比较或排序。

边界情况 / 常见失败
  • 默认只替换每行第一个：s/chr// 一行里有两个 chr 只删第一个，要全删加 g。
  • old/new 里含 / 要转义或换定界符：替换路径 s/\/a\/b/\/x\/y/ 难读，用 s|/a/b|/x/y|。
  • sed 默认不修改原文件：只把结果打到屏幕。想改文件用 -i（概念 3）。
  • 替换里 & 是特殊字符：new 里的 & 表示「匹配到的 old」，要字面 & 得转义 \&。
工程场景 / 为什么需要它

「把 500 个样本名里的 _R1 统一去掉」「把 chr 前缀批量删掉」——这类批量改名，sed 一条命令搞定，比手动一个个改快几千倍。

衔接点

sed 的 old/new 支持 Lesson 07 学的正则（^ $ [0-9]）。概念 2 讲怎么「定位到特定行」再操作。

Concept 2 · Addressing lines: delete / print / ranges

English: sed commands can target specific lines with an address — a line number, a pattern, or a range — combined with d (delete) or p (print, usually with -n).

中文：sed 用「地址」定位到特定行——行号、模式、范围——配合 d（删除）或 p（打印，通常加 -n）。

Syntax：

sed '1,5d' file               # 删除第 1-5 行
sed '/^#/d' file              # 删除 # 开头的注释行
sed '5,20!d' file             # 只保留 5-20 行（! 取反）
sed -n '5p' file              # 只打印第 5 行
sed -n '/TP53/p' file         # 只打印含 TP53 的行（grep 替代）
sed '1,5s/old/new/' file      # 只在 1-5 行内替换

实例：sed '/^#/d' sample.vcf 删掉 VCF 文件所有 # 注释头，只留变异记录——这是生信里洗数据的标准动作。

边界情况 / 常见失败
  • -n 和 p 必须搭配：不加 -n，sed 默认打印所有行，p 会让匹配行出现两次。
  • ! 是取反：5,20!d 是「除 5-20 行外都删」，即只留 5-20 行。
  • 地址和替换可组合：1,5s/old/new/ 只在 1-5 行替换，不是全文。
  • d 是删除整行：想删「行内某个词」用替换 s/word//，不是 d。
工程场景 / 为什么需要它

「删注释行」「只取某几行」「按模式抽行」——sed 的地址定位让它既能洗数据，也能当 grep 用，还能精确到行号。

衔接点

概念 1 是「改内容」，概念 2 是「选行」。概念 3 讲怎么把改动真正写回文件 + 组合多条规则。

Concept 3 · In-place -i + multiple commands + anchors

English: -i writes the result back into the file (-i.bak keeps a backup); multiple rules combine with -e or ;; anchors ^/$ insert at line start/end.

中文：-i 把结果写回文件（-i.bak 留备份）；多条规则用 -e 或 ; 组合；锚点 ^/$ 在行首/行尾插入。

Syntax：

sed -i 's/old/new/g' file          # 原地修改（无备份，危险）
sed -i.bak 's/old/new/g' file       # 先备份成 file.bak 再改
sed -e 's/a/b/' -e 's/c/d/' file    # 两条替换（-e 连接）
sed 's/a/b/; s/c/d/' file           # 同上（分号连接）
sed 's/^/> /' file                  # 每行行首加 "> "
sed 's/$/,/' file                   # 每行行尾加逗号

实例：给一个 FASTQ 的 read 名统一加前缀、同时删掉 chr，一条命令两件事：sed -e 's/^/SRR_/' -e 's/chr//g' sample.txt。

边界情况 / 常见失败
  • -i 会覆盖原文件且不可逆：改错了找不回来。习惯性用 -i.bak 留备份。
  • -i 是 GNU sed 扩展：macOS 的 BSD sed 需要 -i ''，行为不同。
  • 行首/行尾用 ^/$ 锚点：s/^/x/ 在开头插，s/$/x/ 在结尾插，new 里 & 会被当特殊字符。
  • 多条命令顺序执行：s/a/b/; s/b/c/ 先 a→b 再 b→c，顺序影响结果。
工程场景 / 为什么需要它

「给 100 个文件批量加表头 / 去前缀 / 统一格式」——-i 原地修改 + 多条规则，是自动化清洗的核心手段。但一定要先备份。

衔接点

sed 是「行处理」，awk 是「列处理」，两者互补。Lesson 13 xargs 会把 sed/awk 接到「批量处理多个文件」上。

05 Debug Challenge 排错挑战

5 个真实 Ubuntu Server 24.04 会遇到的报错。Problem → Think → Answer → Explanation。

调试 1 · sed 's/chr//' file 一行两个 chr 只删了一个
Problem：想删所有 chr，结果每行只删了第一个。
💭 Think：缺了什么标志？
Answer：加 g：sed 's/chr//g' file。
🧠 Explanation：sed 默认只替换每行第一个匹配，g（global）才替换所有。
调试 2 · sed 's//a/b//x/y/' file 报错 unterminated s command
Problem：替换路径时斜杠冲突，命令解析乱。
💭 Think：斜杠被当定界符了吗？
Answer：换定界符：sed 's|/a/b|/x/y|' file。
🧠 Explanation：s 命令的 / 是定界符，old/new 里有 / 会冲突，用 | 或 # 等别的字符当定界符。
调试 3 · sed -n '5p' file 少了 -n 时输出整份文件
Problem：想只打印第 5 行，结果整份文件都出来了。
💭 Think：sed 默认会打印所有行吗？
Answer：加 -n：sed -n '5p' file。
🧠 Explanation：sed 默认每行都输出，p 命令又打印一次。加 -n 抑制默认输出，只出 p 指定的行。
调试 4 · sed -i 's/old/new/g' file 改错了，想找回原文件
Problem：-i 直接覆盖，原文件没了。
💭 Think：改之前有没有备份？
Answer：没备份找不回。以后用 -i.bak 留备份，改错还能从 file.bak 恢复。
🧠 Explanation：-i 原地写回不可逆。-i.bak 会先复制一份 .bak 再改，是安全习惯。
调试 5 · sed 's/^/> /' file 输出每行行首都有 > 但带了个多余空格
Problem：new 里的空格被当成了替换内容的一部分。
💭 Think：s/^/> / 里 /> / 的空格是故意的吗？
Answer：s/^/> / 就是「> + 一个空格」，想要没空格写 s/^/>/。
🧠 Explanation：替换文本 new 里的每个字符（含空格）都会原样输出，空格也是内容。

06 Engineering Scenarios 工程场景

先写自己的方案，再展开看答案。每个场景想「三个月后的人能否看懂」。

场景 1：500 个样本名的清单，全部带 Sample_ 前缀，要批量改成不带前缀的编号。

参考方案

sed 's/Sample_//' samples.txt——一条命令去掉所有前缀。要写成文件加 -i.bak。

场景 2：一个 VCF 前 50 行全是 ## 和 # 注释，你要只留变异记录。

参考方案

sed '/^#/d' sample.vcf——删掉所有 # 开头的行，剩下的就是变异记录。

场景 3：一个基因坐标文件，染色体写成了 chr1…chrX，下游工具只要数字/字母（不要 chr）。

参考方案

sed 's/^chr//' coords.txt——用 ^ 锚定行首，只删开头的 chr，安全不影响中间可能出现的 chr 字样。

场景 4：要给一个 FASTQ 的 read 名统一加 @SRR_ 前缀，同时把 chr 全去掉，一条命令做完并留备份。

参考方案

sed -i.bak -e 's/^@/@SRR_/' -e 's/chr//g' reads.fastq——两条规则组合 + 备份，一次性改好。
