01 任务背景 · Mission Context

昨天你搭好了目录骨架。今天主管丢给你一份清单：100 个测序文件的路径，名字长这样——SRR12345678_1.fastq.gz、SRR12345678_2.fastq.gz、SRR12345679_1.fastq.gz……

任务是：把这 100 个文件里所有肿瘤样本（文件名带 _1）挑出来，复制到另一个目录，再快速地在数据目录和处理目录之间来回切换。

如果一个个手敲路径，你会疯掉。你需要更聪明的路径技巧：通配符 + 路径工具 + 目录栈。

Context → Need → Tool

文件太多 → 需要批量匹配和快速导航 → 用 glob 通配符、basename/dirname、pushd/popd。

02 知识 · Knowledge（≤20%）

3 个概念。每个：中文 + 英文 + 心智模型 + 语法 + 实例 + 常见错误。

概念 1 · 通配符 Glob：一次匹配一批文件

中文：用特殊符号代替「一批」文件名，一条命令操作多个文件。这是路径最重要的武器。

English: Special characters that match a group of filenames in one command.

语法：

ls *.fastq.gz      # * 匹配任意字符：列出所有 .fastq.gz
ls patient0?.fastq.gz   # ? 匹配单个字符：patient01..patient09
ls patient0[1-3].txt    # [1-3] 匹配 1/2/3
cp {tumor,normal}.bam /backup/   # {a,b} 展开成 tumor.bam normal.bam

实例：ls *.fastq.gz 一条命令列出目录里所有 fastq，不用一个个敲名字。

常见错误

* 不匹配以 . 开头的隐藏文件（如 .bashrc）。想看隐藏文件要用 ls -a。

概念 2 · 路径工具：basename / dirname / realpath / which

中文：把一个路径「拆开」或「定位」。四个命令各管一件事。

English: Split or locate a path with four small tools.

语法：

basename /data/raw/a.fastq.gz   # → a.fastq.gz（文件名）
dirname  /data/raw/a.fastq.gz   # → /data/raw（目录）
realpath .                      # → 当前目录的绝对路径
which ls                        # → /usr/bin/ls（命令在哪）

心智模型：路径 = 目录 + 文件名。dirname 取前面，basename 取最后一段，realpath 把相对变绝对，which 找命令真身。

常见错误

basename 和 dirname 搞反：basename 是「最后一段文件名」，dirname 是「前面的目录」。

概念 3 · 目录栈：cd - / pushd / popd

中文：在多个目录之间快速来回，不用反复敲长路径。

English: Jump between several directories without retyping long paths.

cd -              # 回到上一个目录（只记一个）
pushd /data/raw   # 压入当前目录，再切换到 /data/raw
popd              # 弹出，返回 pushd 之前的位置
dirs              # 查看目录栈

实例：在项目根目录 ~/project 和数据目录 /data/raw 之间反复切换时，pushd/popd 像书签一样方便。

常见错误

pushd 后忘了 popd，目录栈越堆越深；cd - 只记「上一个」，来回切两次就到不了更早的目录。

03 引导练习 · Guided Practice

跟着敲。

mkdir -p demo && cd demo
touch sample1.fastq.gz sample2.fastq.gz sample3.txt
ls *.fastq.gz               # 只列出两个 fastq，sample3.txt 被排除
basename /data/raw/sample1.fastq.gz   # → sample1.fastq.gz
dirname  /data/raw/sample1.fastq.gz   # → /data/raw
which ls                    # → 命令 ls 的位置
cd .. && cd -               # cd - 回到 demo
pushd /tmp && popd          # 压栈切换，再弹回

05 排错挑战 · Debug Challenge

调试 1 · ls *.fastq.gz → No such file or directory

原因：当前目录没有匹配 *.fastq.gz 的文件（通配符没匹配到任何东西，bash 会把字面 *.fastq.gz 传给 ls）。

解决：先 ls 确认目录内容，或 cd 到有 fastq 的目录。

调试 2 · basename 输出的是目录而不是文件名

原因：你可能把 basename 和 dirname 用反了。

解决：basename 取最后一段（文件名），dirname 取前面（目录）。

调试 3 · pushd /data/raw → No such file or directory

原因：/data/raw 这个绝对路径不存在。

解决：先用 ls /data 确认路径，或改用自己确实存在的目录。

调试 4 · cd - → OLDPWD not set

原因：你还没切换过目录，没有「上一个目录」可回。

解决：先 cd 去别处，再 cd - 才有效。

调试 5 · 通配符匹配不到隐藏文件

原因：* 默认不匹配以 . 开头的隐藏文件。

解决：用 ls -a，或显式写 .* 匹配隐藏文件。

06 工程场景 · Engineering Scenarios

场景 1：100 个样本文件里，只把文件名带 _1 的（肿瘤样本）挑出来，你怎么用一条命令匹配它们？

参考思路

ls *_1.fastq.gz。*_1.fastq.gz 匹配任意前缀 + _1 结尾的 fastq。

场景 2：你写脚本时需要一个样本的「文件名」而不是整个路径，用什么命令取？

参考思路

basename。例如 basename /data/raw/SRR12345678_1.fastq.gz → SRR12345678_1.fastq.gz。

场景 3：你常在「项目根目录」和「数据处理目录」之间切来切去，怎么少敲路径？

参考思路

用 pushd 压入两个目录，之后 popd/dirs 快速切换；或至少用 cd - 在两个目录间来回。
