## 本课学了什么（核心知识点）

### 1. 通配符 Glob：一次匹配一批文件
- `*` 匹配任意多个字符：`ls *.fastq.gz`
- `?` 匹配单个字符：`ls patient0?.fastq.gz`
- `[abc]` 字符集：`ls patient0[1-3].txt`
- `{a,b}` 花括号展开：`cp {tumor,normal}.bam backup/`
- ⚠️ `*` 不匹配隐藏文件（以 `.` 开头）

### 2. 路径工具：basename / dirname / realpath / which
- `basename /data/raw/a.fastq.gz` → `a.fastq.gz`（文件名）
- `dirname  /data/raw/a.fastq.gz` → `/data/raw`（目录）
- `realpath .` → 当前目录的绝对路径
- `which ls` → 命令 `ls` 的位置

### 3. 目录栈：cd - / pushd / popd
- `cd -` 回到上一个目录
- `pushd 目录` 压入并切换；`popd` 弹回；`dirs` 查看目录栈

## 费曼复述（我自己的话）

> 对于这些通配符而言，我觉得 * 是最方便的，能查找大概部分的信息（比如说，我们需要再一个很大的文件夹中找到以.fastq.gz结尾的文件，那么使用 * 就很方便查找）
>
> 但是对于 ？ 单个字符的情况来说 比如说我们就在一个有很多.fastq.gz结尾，并且开头以patient + ID号的话，如果我们需要快速查找，范围在10-19的ID的病人的数据，那么这个就很有用了
>
> 而 [ 范围 ] ,这个相对于前面两个来说查找范围就更小了
>
> { } 这个也是一样
>
> 而这个目录栈就相当于一个 大笼子（有很多层，每层必须是上面没有小笼子的时候才能移动），那么我最下面关了鸭子，在这上面我关了鸽子 ，由上往下看，我就只能看到鸽子那一层，所以我的目光就停留在鸽子身上（就相当于我在我pushd上去的这一层），之后我想回到鸭子那一层，我就得把这个鸽子的笼子扔出去（弹出去：popd）那么我的目光就在鸭子这一层了，那么我现在看一下笼子组成啥样的( dirs一下 )那么就能看到只剩鸭子这一层了，所以我目光在鸭子这一层，就是这么工作的，可能说的有些复杂，但是我自己弄懂了

## 记忆锚点

- `*` 是「任意多」，`?` 是「恰好一个」
- `basename` 取文件名，`dirname` 取目录（别搞反）
- `pushd` 和 `popd` 成对使用，像书签
