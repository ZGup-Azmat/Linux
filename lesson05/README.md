## 本课学了什么（核心知识点）

### 1. Vim 三种模式
- 普通模式（移动/删除/复制，启动默认）、插入模式（i 进入）、命令行模式（: 进入）
- `i` 进入插入 → `Esc` 回普通 → `:wq` 保存退出 / `:q!` 放弃退出
- ⚠️ 卡住就按 Esc；`:q` 改了没存会报 E37

### 2. Vim 编辑命令
- 移动 hjkl / w b / 0 $ / gg G
- dd 删行、yy 复制、p 粘贴、u 撤销
- `/pattern` 查找、`:%s/old/new/g` 全文替换
- ⚠️ 替换漏 `/g` 只换每行第一个

### 3. tmux：会话 / 窗口 / 窗格
- `tmux new -s name` 建会话、`tmux ls` 列、`tmux attach -t name` 接回
- `Ctrl-b d` 脱离（任务继续跑）、`Ctrl-b %`/`"` 分屏、`Ctrl-b 方向键` 切换
- ⚠️ 前缀是 Ctrl-b，不是 Ctrl-c

## 记忆锚点

- Vim = 三模式：普通 / 插入 / 命令行，Esc 永远是救命键
- `dd` 是剪切（能 p 回来），`u` 撤销
- tmux 让任务「长在服务器上」，断线不死
- prefix = Ctrl-b
