## 本课学了什么（核心知识点）

### 1. 三条流 + 基础重定向
- 每个进程有三条流：stdin(0) / stdout(1) / stderr(2)
- `>` 覆盖写 stdout、`>>` 追加、`<` 喂 stdin
- ⚠️ `>` 会静默覆盖；`>` 只重定向 stdout，stderr 仍上屏

### 2. stderr 重定向
- `2>` 单独重定向 stderr，`2>/dev/null` 静音
- `2>&1` 把 stderr 合并到 stdout 去向；`&>` 一次重定向两者（bash）
- ⚠️ 顺序极重要：`> file 2>&1` 对，`2>&1 > file` 错

### 3. /dev/null + heredoc / here-string
- `/dev/null` 黑洞丢弃一切输出
- heredoc `<< EOF ... EOF` 写多行（结束标记顶格）
- here-string `<<<` 喂单行（bash）
- ⚠️ EOF 前有空格就不结束；带引号的 EOF 禁止变量展开
