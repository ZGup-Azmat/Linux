## 本课学了什么（核心知识点）

### 1. 模式-动作模型 + 字段
- `awk '{print $1}'` 按行拆字段，$1/$2 是列，$0 是整行
- `-F '\t'` 指定分隔符（默认连续空白）
- ⚠️ awk 程序必须单引号包起来，否则 shell 抢 $1

### 2. 内建变量
- `NR` 行号、`NF` 字段数、`$NF` 最后一列、`FS`/`OFS` 输入输出分隔符
- ⚠️ NR 跨文件不重置（每个文件用 FNR）；print 逗号默认空格连接

### 3. 条件过滤 + BEGIN/END + 计算
- `$2 > 100 {print}` 模式过滤；`BEGIN` 加表头、`END` 算总和/平均
- `{sum += $2} END {print sum}` 求和
- ⚠️ 数值字段要干净（NA/带单位会破坏比较）；`==` 是比较、`=` 是赋值

## 记忆锚点

- grep 找行，awk 拆列 + 算数
- $0 整行、$1/$2 列、$NF 最后一列、NF 字段数、NR 行号
- awk 脚本永远单引号
- BEGIN 开头跑一次、END 结尾跑一次
- 求和 `{s+=$2} END{print s}`，平均再加 `n++` 和 `/n`
